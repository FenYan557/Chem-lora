# DeMol 架构说明（对照论文核对用）

论文：Liu et al., ICLR 2026, *Enhancing Molecular Property Predictions by Learning
from Bond Modelling and Interactions*。无官方代码，本实现按论文 §3.2、eq. (5)–(10)、
Figure 3（Double-Helix block）与 Appendix B Algorithm 1 复现。

本文档逐项给出"论文定义 → 代码位置 → 关键代码"，并标明每一处论文表述含糊时
我们做的解释选择（这些地方最需要人工确认）。

## 2. 整体数据流

DeMol 是**双图 Transformer**：一个分子同时表示成

* 原子图：N 个原子节点，表示 `h_a ∈ R^{N×d_atom}`；
* 键图（线图 line-graph）：M 条化学键节点，表示 `h_b ∈ R^{M×d_bond}`，
  两条键共享一个原子时在线图里相邻。

每个 Double-Helix block（对应 Figure 3）做一次"对称的横档"：

```
h_a ──[原子自注意力 + FFN，加性偏置 Φ]──> h_a'
h_b ──[键自注意力 + FFN，加性偏置 Φ_b]──> h_b'
h_a' ──[atom←bond 交叉注意力 + FFN]───> h_a''        (eq. 9)
h_b' ──[bond←atom 交叉注意力 + FFN]───> h_b''        (eq. 10)
```

注意两个交叉注意力都读**自注意力之后**的表示（`h_a'`、`h_b'`），所以每层是
对称的而不是串行的——这一点直接体现在代码里：

```python
# demol/model.py, DoubleHelixBlock.forward
h_a1 = self.atom_self(h_a, None, phi_a, atom_mask)
h_b1 = self.bond_self(h_b, None, phi_b, bond_mask)
h_a2 = self.atom_cross(h_a1, h_b1, bias_ab, bond_mask)
h_b2 = self.bond_cross(h_b1, h_a1, bias_ba, atom_mask)
return h_a2, h_b2
```

## 3. 结构编码（eq. 5 与 Φ 的组合）

所有几何/拓扑信息都编码成**加性注意力偏置**（scalar-per-head-per-pair），
不进入 token 本身。

### 3.1 高斯基核（eq. 5）

$$\varphi_k(x) = -\frac{1}{\sqrt{2\pi}|\sigma_k|}
\exp\Big(-\tfrac12 \big(\tfrac{\alpha x+\beta-\mu_k}{\sigma_k}\big)^2\Big),
\quad \mu_k = \frac{w(k-1)}{K},\ \sigma_k = \frac{w}{K}$$

α、β 是按**节点类型对**索引的可学习标量（原子通道用原子类型对，键通道用
键类型对，atom-bond 交叉通道用矩形表）：

```python
# demol/encoding.py, GaussianBasis.forward
a = self.alpha[ti[:, :, None], tj[:, None, :]].unsqueeze(-1)
b = self.beta[ti[:, :, None], tj[:, None, :]].unsqueeze(-1)
z = (a * x.unsqueeze(-1) + b - self.mu) / self.sigma
return self.norm * torch.exp(-0.5 * z * z)   # (B, X, Y, K)
```

`gaussian_centers` 实现 μ/σ 的定义（注意 1-based 的 k 对应 `arange(K)`）：

```python
mu = width * k / n_kernels                    # k = 0..K-1 ↔ 论文的 k-1
sigma = torch.full((n_kernels,), width / n_kernels)
```

基函数**全层共享**（`DeMol.__init__` 里 `basis_aa/basis_bb/basis_tors/basis_ab`
各建一次）；每层各自拥有把 K 维基投成注意力偏置的 W1/W2（eq. 6 上方的
Φ = GELU(φW1)W2），即论文"layer-specific Φ^(l)"的读法，与 Transformer-M 一致：

```python
# demol/encoding.py, ScalarBasisEncoder.forward
out = self.fc2(F.gelu(self.fc1(phi)))         # (B,X,Y,K)->(B,X,Y,H)
return out.permute(0, 3, 1, 2)                # (B,H,X,Y) 加性偏置
```

### 3.2 三个偏置的组合

```python
# demol/encoding.py
AtomStructureEncoding:   Φ   = Φ_dist + Φ_SPD                    # 原子对原子
BondStructureEncoding:   Φ_b = Φ_dist + Φ_SPD + Φ_tors           # 键对键
CrossStructureEncoding:  Φ_x = Φ_dist + Φ_SPD                    # 原子对键
```

* `Φ_dist`：高斯基展开成对距离。原子通道用原子间欧氏距离；键通道用**键中点**
  之间的距离；atom-bond 通道用"原子到键中点"的距离。
* `Φ_SPD`：最短路径距离的可学习嵌入（分桶，0..15 + 16 表不可达）。
  atom-bond 通道的图距离取 `min(SPD[i,u], SPD[i,v])`（u,v 是键的两个端点）。
* `Φ_tors`（仅键通道）：相邻键对的扭转角余弦再过同一组高斯基。线图邻居用
  键间夹角 θ_ijk，非邻居用二面角 φ_ijkl；输入前先做 `(cos+1)/2` 归一到 [0,1]，
  所以这一支的 `width=1.0`。

## 4. 注意力与掩码

所有注意力都是同一个 `MaskedMultiHeadAttention`：QK^T/√d **加上结构偏置**、
按掩码屏蔽、softmax、加 dropout、乘 V。掩码有两层，取交集：

- **padding 掩码**（`key_mask`，(B, Y)）：屏蔽补齐的虚拟原子/键；
- **结构感知掩码**（`pair_mask`，(B, X, Y)，论文 3.2 节）：原子自注意力用
  `aa_mask`（5 Å 截断 + 成键 + 自身），键自注意力用 `bb_mask`（线图邻接 +
  共轭两跳 + 自身），两条交叉注意力共用 `ab_mask`（原子-键关联；键→原子
  方向取转置）。这正是附录 C 复杂度从 O(M^2) 降到 O(M) 的依据。

```python
# demol/model.py, MaskedMultiHeadAttention.forward
logits = torch.matmul(qh, kh.transpose(-1, -2)) * self.scale
if bias is not None:
    logits = logits + bias                    # 结构偏置加在这里
km = key_mask[:, None, None, :]
if pair_mask is not None:
    km = km & pair_mask[:, None, :, :]        # 结构感知掩码在这里并入
logits = logits.masked_fill(~km, torch.finfo(logits.dtype).min)
attn = torch.softmax(logits, dim=-1)
# 整行 key 全被 mask 的 query（只发生在 padding 行）输出 0 而不是 NaN/均匀分布
attn = torch.where(km.any(dim=-1, keepdim=True), attn, torch.zeros_like(attn))
```

每个注意力子层配一个 FFN，Pre-LN + 残差（`SubLayer`）。交叉注意力里
context 流有自己的 LayerNorm（`ctx_norm`），因为 `ln_attn` 属于 query 流。

论文 Table 1 标称 186 M 参数，但按"每层 4 个注意力子层 × 各自 **mult=4** 的 FFN"
的直读实现是 ~350 M。用论文自己的 Table 1 反推：同表 Graphormer = 47.1 M，
对应 L=12、d=768、**FFN 隐藏维 = d（mult=1）** 的公开配置，数字精确吻合；
D.1 也说 "Similar to Graphormer, Transformer-M and Uni-Mol"。把 FFN 改成
mult=1（保留四个独立 FFN）后本仓库实测 **180.7 M**，与 186 M 只差 ~3%
（差值在读出头/词表等论文未展开的细节）。所以论文模型几乎可以肯定用的是
Graphormer 式的小 FFN，而不是 BERT 式 4 倍 FFN。**`paper` 预设已改为
`ffn_mult=1`**（其余预设维持 mult=4，因为它们是我们自己的本地尺寸，不对应论文）。
README "参数量"一节有完整的变体实测表。

## 5. 读出与四个预训练头

```python
# demol/model.py, DeMol.forward 末尾
graph_repr = cat([masked_pool(h_a, atom_mask, ("mean","sum")),
                  masked_pool(h_b, bond_mask, ("mean", "sum"))], dim=-1)
prop = self.prop_head(graph_repr)             # (B, 12)  ← 主任务

atom_logits = self.mask_head(h_a)             # Lmask：被 mask 原子的类型分类
coord_pred  = pos_in + self.coord_head(h_a)   # Lcoord：加噪坐标 -> 预测位移
left, right = self.bond_left(h_a), self.bond_right(h_a)
bond_logits = (L R^T + (L R^T)^T) / √r + bias # Lbond：低秩对称打分，判断原子对是否成键
```

* **Lprop**：图级回归。读出是原子流与键流各做 mean+sum 池化后拼接
  （d_readout = (d_atom + d_bond) × 2），过一个两层 MLP。**注意：头是
  单个 `Linear(d_readout, 12)`，12 个目标共用一套权重；"多任务"只体现在
  损失层 `LossConfig.target_indices` 选哪些列参与，不在头的结构上。**
* **Lmask**：随机 mask 掉一部分原子的类型字段（换成可学习 `[MASK]` 向量），
  逐原子分类回原类型。
* **Lcoord**：输入坐标加 σ=0.1 Å 高斯噪声，让模型预测回干净坐标
  （实现上预测"位移 delta"，等价）。
* **Lbond**：原子对二分类"是否成键"，打分矩阵强制对称
  `(S + S^T)/√r + b`，低秩 r = d_atom/4。

微调时辅助头整头丢弃（`load_pretrained(strict=False)`），损失里
`w_mask = w_coord = w_bond = 0`，只剩 Lprop（MSE + 单目标）。

## 6. 论文表述含糊处的解释选择（核对重点）

| # | 问题 | 我们的选择 | 代码位置 |
| --- | --- | --- | --- |
| 1 | eq. 6 的注意力是多头，但 Φ 写成 N×N 单标量 | 默认**每头一个偏置**（`per_head_bias=True`，同 Transformer-M）；`False` 退化为论文字面 | `DeMolConfig.per_head_bias` |
| 2 | eq. (9) 给 atom×bond 注意力加的是 Φ^(l)[i, j]（下标本是原子对） | 用 j = 该键的**另一个端点** gather Φ^(l)[i, j]（`use_endpoint_bias=True`），另加专用的 atom-bond 编码 Φ_x | `DeMol.forward` 里的 `other`/`bias_ab` |
| 3 | Φ^(l) 是否每层独立 | 结构编码每层独立（默认）；交叉编码默认全层共享（`share_cross_encoding=True`） | `atom_enc/bond_enc/cross_*_enc` |
| 4 | 186 M 参数量对不上 | 已定位：论文是 Graphormer 式 `ffn_mult=1`（实测 180.7 M ≈ 186 M）；`ffn_mult=4` 是我们的初始误读 | README 参数量一节 |
| 5 | Lcoord 是预测坐标还是噪声 | 预测位移（`coord_target="delta"`，等价于恢复坐标）；也实现了 `"noise"` | `DeMolConfig.coord_target` |
| 6 | 键级/芳香性从哪来（QM9 xyz 不给） | 有 rdkit 用 rdkit；没有则按 Appendix B Algorithm 1 + 键长比纯几何推断 | `chem.py` / `features.py` |
| 7 | Lbond 的负样本集合 | 同一原子掩码内、未成键的原子对（README 偏差 #8） | `losses.py` |
| 8 | 预训练默认监督目标 | 默认 `--targets all`（12 个一起）；论文 Appendix D.1 只监督单个 gap | `run_pretrain.py --targets` |
