# 第一部分 · 怎么向审稿人证明两件事

## 0. 先把两类主张分开

审稿人会问的其实是两个独立问题，混在一起答会两边都答不实：

| 主张 | 审稿人的原话 | 证据类型 |
|---|---|---|
| **A. 子集分布合理** | "凭什么叫这 5 万代表 345 万？" | 分布层面的统计检验（边际分布、KS、卡方、覆盖度） |
| **B. 簇内分子确实相似** | "你的簇是不是 UMAP 画出来的幻觉？" | 结构层面的化学一致性（kNN 纯度、骨架集中度、子结构富集） |

A 决定"子集能不能替代全量"，B 决定"你的方法有没有意义"。**A 可以不需要 B 成立**（纯随机抽样 A 也成立），所以必须额外回答"那你为什么要聚类"——这是第 1.4 节，也是本文最关键的一节。

## 1. 主张 A：子集分布合理

### 1.1 构造性论证（零成本，已完成）

分层等比例抽样在数学上就是无偏的，这一点先写死：**每个簇（含噪声层）的抽样配额 = 簇大小 × 全局比例，层内纯随机**。所以子集是全量的一个无偏样本，不需要额外假设。

已实测的支撑数字（可直接进论文表格）：

| 模型 | 簇数 | 噪声层规模 | 每簇抽样率区间 | 抽样率中位数 | 子集与全量的总变差距离 TV |
|---|---|---|---|---|---|
| molformer | 271 | 1,374,495 (39.82%) | 1.418% – 1.473% | 1.448% | 0.0011 |
| chemberta2 | 338 | 1,049,896 (30.41%) | 1.423% – 1.475% | 1.448% | 0.0012 |
| morgan | 141 | 1,501,832 (43.50%) | 1.425% – 1.483% | 1.449% | 0.0006 |

全局比例 = 50,000 / 3,452,095 = **1.4484%**。三个模型每簇抽样率的中位数都精确落在这个值上。

**噪声层没有被特殊对待**：molformer 噪声层 19,908 / 1,374,495 = 1.4484%，chemberta2 15,207 / 1,049,896 = 1.4484%，morgan 21,752 / 1,501,832 = 1.4484%。三层都和全局比例一致，这是"没有偷偷给稀有结构加权、也没有丢弃孤立点"的硬证据。

### 1.2 抽样率的波动 = 二项噪声，不是偏差（低成本，待算）

抽样率在 1.418%–1.483% 之间浮动，审稿人可能问"为什么不都是 1.448%"。答案：配额取整 + 有限总体抽样必然产生波动，且波动幅度可预测。

要做的检验（两个，都便宜）：

1. **二项波动核对**：对每个簇，理论标准差 σ_i = sqrt(p(1−p)/N_i)，p = 0.014484。把"观测到的每簇抽样率偏离"除以 σ_i 得到 z 分数，画 z 的分布。若 z 近似 N(0,1)（例如 95% 落在 ±1.96 内），说明波动纯粹来自随机性，无系统性偏差。
2. **卡方拟合优度检验**：H0 = "抽中数服从按簇大小的多项分布"。计算 χ² = Σ (n_picked_i − E_i)² / E_i，E_i = N_i × p，自由度 = 簇数 − 1。报告 χ²、df、p 值。**若 p > 0.05，一句话就能写死："cannot reject that the subset is a strictly proportional sample"**。这是审稿人最容易接受的单个统计量。

### 1.3 多维边际分布对比（中成本，待算）★ 最关键的一块

目前所有验证都只覆盖 **embedding 空间**的分布。embedding 是代理量，审稿人一定会追问目标性质和化学本身。要补三层：

**第一层：标签 y（HOMO-LUMO gap）**

- KS 统计量 + p 值（子集 vs 全量 train）
- 直方图叠加图 + 变差距离 TV
- 分位数表：1% / 5% / 25% / 50% / 75% / 95% / 99% 七个点，子集与全量并排
- y 的均值、标准差、偏度、峰度对比

y 在原始 jsonl 里（parquet 缓存只有 `smiles, split` 两列，需要回原始数据取，或重建一个带 y 的 parquet）。

**第二层：RDKit 独立物性（不依赖 embedding，用来兜住 embedding 的盲维）**

逐个算 KS：分子量 MW、LogP、TPSA、环数、芳香环数、杂原子数、可旋转键数、H 供体/受体、BertzCT、fraction Csp3、手性中心数。

这一层的作用是回答"如果 embedding 没有编码某个化学维度怎么办"。物性是独立于三个 embedding 模型的第三方度量，两边都对齐，说服力完全不同。

**第三层：Bemis-Murcko 骨架频率 ★ 化学审稿人最认这个**

- 全量与子集各自统计骨架，取全量 Top-50 骨架，并排比较其在两边的占比
- 报告骨架层面的 TV 距离和 KS
- 报告"子集覆盖了多少种全量出现过的骨架"（覆盖率）以及"子集里出现了多少种全量没有的骨架"（应为 0，因为子集是全量的子集——这条是免费的完整性检查）

骨架占比匹配 = 一个药化背景的审稿人看一眼就能判断"这子集像不像原数据集"。比任何 embedding 空间的指标都直观。

**输出形式建议**：一张大表，行 = 指标（y、MW、LogP、…、Top-50 骨架合计），列 = [全量均值, 子集均值, KS 统计量, p 值, 随机基线 KS]。**最后一列"随机基线"必须有**，见下节。

### 1.4 正面回答"为什么不直接随机抽"（必须写，否则前面全白做）

这是这类论文被拒的头号原因。已实测的覆盖度结果是：

- UMAP 空间：分层随机 vs 纯随机 = **+0.4% / +0.4% / +0.1%**
- 原生 embedding 空间：**−0.0% / −0.0% / −0.1%**

也就是说**两者覆盖度打平**。这个结果如果直接写进论文而不解释，审稿人立刻会问"那你的聚类有什么价值"。

正确的回答有三条，都要写：

**（1）纯随机抽样会整簇漏掉小簇，分层配额不会。**

对一个大小为 N 的簇，纯随机抽 5 万（p = 0.014484）完全漏掉它的概率是 (1−p)^N：

| 簇大小 N | 纯随机完全漏掉的概率 |
|---|---|
| 300（= min_cluster_size 下限） | **1.26%** |
| 500 | 0.07% |
| 1,000 | 5.4 × 10⁻⁷ |

而分层配额给每个簇的配额是**确定性**的（round(N_i × p)，最小为 1），所以**每个簇都保证至少有一个代表**。以 molformer 的 271 个簇为例，若其中有 k 个簇大小在 300–500 之间，纯随机的期望漏簇数约为 k × 1%。

> 待办：从 `profile_full/*_cluster_table.csv` 统计 Σ(1−p)^{N_i}，得到三个模型各自的"纯随机期望漏簇数"。这是一个非常有说服力的单句论据，本地即可算，几秒钟。

**（2）聚类提供了可审计性。** 随机抽样给不出"子集覆盖了哪些化学家族"的任何表述；分层抽样能直接给出每簇大小、抽中数、抽样率、示例结构的完整表格（`profile_full/` 里已经有了），审稿人可以逐簇核对。这在方法学上是实质差异，不是包装。

**（3）分层让"分布匹配"变成一个可检验的命题。** 有了簇标签，才能算 TV、才能做卡方检验、才能报告"每簇抽样率都是 1.448%"。纯随机抽样只能说"应该差不多"，给不出逐层的量化保证。

> 写作建议：不要用"我们的方法覆盖度更高"这种话——数据显示是打平，硬吹会被抓。改成 **"在覆盖度与随机抽样持平的前提下，我们的方法额外保证了每个化学家族的非空代表性，并提供了可逐层审计的分布匹配证据"**。这个表述准确且无法反驳。

### 1.5 覆盖度的正确表述（已有数据，需重写）

已测指标是"子集点到全量点的最近邻覆盖"。建议在论文里同时报两个方向：

- **覆盖方向**：从全量随机取 10 万个探针点，算每个探针到最近子集点的距离，报告均值 / 中位数 / 95 分位。对比对象 = 同规模纯随机子集。
- **保真方向**：算子集内每个点到全量中最近邻的距离，检验子集没有偏向某个特殊区域（比如全是簇心或全是边缘点）。

现有结果（±0.1%~0.4%）说明两个方向都与随机持平，配合 1.4 的论述使用。

### 1.6 稳定性（低成本，待算）

- **换随机种子**：用 3 个不同 seed 各抽一次 5 万，报告三者两两之间的 TV 距离和 y 分布 KS。若都很小，说明结论不依赖某次抽签。注意：三个子集的分子重合度会很低（这正常），要看的是**分布指标是否稳定**，不是集合是否相同。
- **换 embedding 模型**：已有三套子集，跨模型 Jaccard ≈ 0.007，说明选出的分子几乎完全不同，但每套都通过了分布匹配 QA。**这本身就是一个强结论**：分布匹配不依赖于用哪个 embedding 做分层，方法对 embedding 选择鲁棒。这条一定要写。

### 1.7 终极证据：便宜的下游代理实验（强烈建议做）

完整预训练很贵，但审稿人真正想看的"子集能否替代全量"可以用一个**分钟级**的代理实验回答：

用 embedding 作特征，训练一个轻量回归器预测 y，三组对比：

| 训练集 | 规模 | 说明 |
|---|---|---|
| 全量 train | 337 万 | 上界参考 |
| 纯随机子集 | 5 万 | **最关键的对照组** |
| 分层子集（本文方法） | 5 万 | 待验证 |

模型用 Ridge / LightGBM / 3 层 MLP 即可，在 embedding 上跑，CPU 或小卡几分钟。评估集 = 官方 valid（**必须先完成 split 过滤，见第二部分 P0**）。

报告 valid MAE。三种可能结果都有价值：

- 分层 ≈ 随机 ≈ 全量 → 说明 5 万已饱和，子集选法不敏感（也是结论，且支持"用小规模就够"的主张）
- 分层 ≈ 随机 < 全量 → 规模不够，需要加大子集
- 分层 > 随机 → **本文方法的核心卖点，直接进摘要**

> 这个实验的性价比远高于任何分布指标，因为它直接对齐项目的最终判据。建议在正式预训练之前先做，用它来决定子集规模（5 万 vs 10 万）和选哪个 embedding 的子集——否则那两个决定是盲拍。

## 2. 主张 B：簇内分子确实相似

### 2.1 kNN 标签纯度 ★ 最直观、最难反驳

对每个分子，在**原生 embedding 空间**（不是 UMAP，UMAP 会扭曲距离）找 k = 50 个最近邻，统计其中与它同簇标签的比例。报告全体的均值、中位数、以及分布直方图。

- 纯度 ≈ 1.0 → 簇在局部完全连贯
- 纯度 ≈ 0.5 → 簇边界模糊，需要调参或改说法

关键细节：**必须在原生空间算，不能拿 UMAP 坐标算**，否则是循环论证（UMAP 布局本身就受聚类影响）。同时报一个 null 基线：把标签随机打乱后重算纯度，真实值应远高于打乱值。

计算成本：345 万 × 3 模型的 kNN，用 GPU（cuml NearestNeighbors）或分批 CPU 都可行；也可以只在 50 万随机样本上算，结论同样成立。

### 2.2 骨架集中度 + 置换检验 ★★ 杀手锏

这是对化学审稿人最有力的一招，因为它有**统计对照**，不是"你看这些分子长得像"的主观断言。

做法：

1. 对每个簇，统计其成员的 Bemis-Murcko 骨架分布
2. 计算两个量：**Top-1 骨架占比**（最大骨架覆盖该簇多少比例成员）和**骨架熵**（越低越集中）
3. **置换检验**：把 345 万个分子的簇标签随机打乱 100 次，每次重算 Top-1 骨架占比与骨架熵，得到 null 分布
4. 报告真实值 vs null 分布的位置，给出经验 p 值

预期结果：真实簇的 Top-1 骨架占比会显著高于打乱后的 null（打乱后每个"簇"是随机分子集合，骨架极度分散）。一张箱线图 + 一句 "p < 0.001, 100 permutations" 就能把"簇有化学意义"这件事钉死。

> 这是整个论证包里最值得优先做的一项：成本低（骨架计算 + 100 次置换，纯 CPU），说服力最高，且同时服务于主张 A 的骨架分布分析（1.3 第三层）——一次计算两处复用。

### 2.3 子结构富集表（把现有轶事变成系统证据）

目前手上已有的定性观察（都来自 `profile_full/*_cluster_table.csv` 的每簇 12 条示例 SMILES）：

- molformer C50（196,980 个分子，最大簇）：12 条示例**全部**含 `C=C` 或 `C#C`
- molformer C0：全部含 `N#C`（腈基）
- molformer C86：全部含 `/C(O)=N\`（肟/酰胺构型）
- chemberta2 C33：全部含 `C#N`
- morgan C0：全部含硝基
- morgan C23：全部为氟代芳环
- morgan C50：全部含 Boc 保护基

这些是很好的口头证据，但"12 条示例"在论文里站不住（审稿人会说 cherry-picking）。系统化做法：

1. 准备一组 SMARTS 查询（常见官能团 100–300 个，可直接用 RDKit 的官能团列表或 ChemBL/公开 SMARTS 集）
2. 对每个簇 × 每个 SMARTS，算富集倍数 = (簇内命中率) / (全量命中率)，配合 Fisher 精确检验
3. BH 法做 FDR 校正
4. 输出每簇 Top-5 富集子结构表，附倍数与 q 值

产出形式：一张表 + 一句话，例如"271 个簇中有 X 个簇存在 q < 0.01 且富集倍数 > 10 的特征子结构"。这个数字本身就是簇化学有效性的量化答案。

### 2.4 簇解释 y 方差的比例（ANOVA η²）★ 把化学结构和目标性质挂钩

前面所有 B 类证据都只说"簇内结构相似"。审稿人真正关心的是**"结构相似是否意味着性质相似"**——因为你的下游任务是预测 y。

做法：单因素 ANOVA。

- η² = 簇间平方和 / 总平方和，即"知道一个分子属于哪个簇，能解释 y 的多少方差"
- 同时报告每个簇内 y 的标准差 vs 全量 y 的标准差的比值
- 对照组：把标签打乱后重算 η²（应接近 0）

如果 η² 达到 0.3–0.5，可以写：**"聚类结构捕获了目标性质的 X% 方差，说明簇划分与下游任务相关，而非仅是 embedding 空间的几何产物。"** 这一句把主张 B 和项目目标直接连起来，价值极高。

> 注意一个诚实的边界：噪声层占 30%–44%，这部分点不参与簇间方差解释。报告时要说明 η² 是在全体上算还是仅在簇内点上算，两个都给最稳妥。

### 2.5 轮廓系数：原生空间与 UMAP 空间分别报

- **原生空间 silhouette**（用余弦距离，因为已 L2 归一化）：这是诚实的数字，通常偏低
- **UMAP 空间 silhouette**：会明显更高，但要标注清楚是在降维空间算的

两个都报，并解释差异来源。只报 UMAP 的会被质疑"降维制造了分离"。

已有的相关数字：PCA 预压缩保留方差 molformer 78.99% / chemberta2 94.28% / **morgan 46.50%**。morgan 这一项偏低，需要在文中说明（摩根指纹是 2048 维稀疏 0/1 向量，方差高度分散，46.5% 属正常），否则审稿人会抓 morgan 的结果不可信。

### 2.6 参数敏感性（中等成本）

用 `min_cluster_size` ∈ {100, 300, 1000} 各跑一次，报告：

- 簇数与噪声率的变化
- 三次结果两两之间的 Adjusted Rand Index（ARI）与 Normalized Mutual Information（NMI）
- 2.2 的骨架集中度是否保持稳定

目的：证明簇结构不是某一组参数的偶然产物。ARI > 0.7 就可以说"结构对参数稳健"。

### 2.7 图：每簇 N 个分子的网格图（可视化证据）

审稿人需要一张能一眼看懂的图。建议规格：

- 选 8 个簇（前 6 大簇 + 中位簇 + 噪声层），每簇随机取 6 个分子
- 网格布局，每格下方标 SMILES 截断 + 簇号
- **一簇一行或一列，不要混排**——混排就看不出"同簇相似"
- 图注写明"每格为该簇内随机抽取的分子，非人工挑选"（这句很重要，防 cherry-picking 质疑）

现状：`cards/` 下已有 24 张单分子卡片，但**大部分中间结构区是空白的**（RDKit 2026.09 的绘图接口问题，见第四部分已知问题）。需要修复后重出，且建议改成"一簇多分子"的网格而不是"一张图一个分子"。

## 5. 审稿人最可能问的五个问题

**Q1：为什么用三个 embedding？最后用哪个？**
目前的答案是"三个都做了对比"，但 Jaccard ≈ 0.007 意味着三批分子几乎不重叠，预训练不可能三个都跑。**必须先用 1.7 的代理实验定出一个**，否则这个问题无法回答。这是待拍板事项，不是写作问题。

**Q2：噪声率 40% 是不是太高了，聚类是不是失败了？**
回答要点：(a) 噪声率不是质量指标，把它压到 5% 只需调小 `min_cluster_size`，代价是产生几百个垃圾簇；(b) 噪声层按同比例 1.448% 抽样，对分布匹配无任何影响；(c) morgan 噪声率最高（43.5%）符合预期，因为稀疏 0/1 指纹空间密度天然不均。**但这个回答需要 2.1/2.2 的数据支撑才有力**，光讲道理不够。另外有一个真实嫌疑待查：50 万 fit + `approximate_predict` 推全量会系统性抬高噪声率，查法是比对 fit 那 50 万自己的噪声率（见第二部分 P1）。

**Q3：5 万这个规模怎么定的？**
目前没有依据，是拍的。诚实的做法是用 1.7 的代理实验扫规模（1 万 / 5 万 / 10 万 / 50 万），画出 valid MAE vs 子集规模的曲线，找拐点。**这张图本身就是论文的一个主要贡献**，比任何分布指标都值钱。

**Q4：子集里有没有 valid 的分子？**
**现在的正确答案是"有，约 1,065 条"，这是缺陷，必须先修**（第二部分 P0）。修完才能回答"没有，全部来自 train"。在这个问题修复之前，任何下游实验结果都不可信。

**Q5：重复 SMILES 怎么处理的？**
全量 3,452,095 行，unique SMILES 3,322,984，重复率 3.74%。当前**未去重**，而且这是**正确的**：等比例抽样天然按出现频次加权，出现两次的分子进子集的概率就是两倍，恰好复现全量分布。去重反而会扭曲分布。这一点可以主动写进论文，是个加分的严谨性细节。需要说明的只是：若判据换成"覆盖多少种不同骨架"，统计口径应在去重后进行。

### 3. 采样策略的关键转向（本轮最重要的方法论决定）

原方案（见 `HDBSCAN_子集筛选_实现逻辑.md`）是 **sqrt(簇大小) 配额 + medoid + 最远点采样 FPS**。本轮换成 **正比配额（`--quota-power 1.0`）+ 簇内纯随机（`--within random`）+ 噪声层按实测噪声率单独成层随机抽**。

理由：判据是"子集分布匹配全量"，不是"稀有结构尽量覆盖"，这两个目标对应相反的采样策略。

- sqrt 配额会**压平**大簇、抬高小簇的抽样率，这是刻意偏离全量分布，方向反了
- medoid + FPS 是确定性挑中心点/极端点，同样偏离随机分布
- 只有"每层等比例 + 层内随机"在数学上保证子集是全量的无偏样本

## 二、P0 问题：抽样未过滤 split（必须修）

证据链：

- `server_scripts/mol_io.py:61` 的 `load_smiles()` 注释写明返回 "covering every molecule in the dataset"；`mol_io.py:74` 按文件名把 valid chunk 标为 `"valid"`、其余标 `"train"`，两者在同一个 DataFrame 里返回
- 三个 embedder 都直接 `df = load_smiles()`（`embed_molformer.py:61`、`embed_chemberta2.py:70`、`embed_morgan.py:59`），无 split 筛选
- `cluster_subset.py` 中搜不到 `split` 的任何使用（唯一命中是 `args.emb.split(",")`，字符串切分）；`cluster_full.sh` 也没有

**后果**：valid 有 73,545 行，占全量 2.13%，等比例抽样后子集里约有 **1,065 条 valid 分子**。PCQM4Mv2 的官方 valid 即评估集，用这 5 万预训练再在 valid 上测，这 1,065 条构成直接泄漏，指标虚高且幅度不可控。

**修法**：`load_smiles()` 之后加 `df = df[df.split == "train"]`，重跑聚类+抽样。**embedding 不用重算**（按索引切片复用），每模型约 3 分钟。同时建议子集 CSV 直接带上 `split`、`y`、原始行号三列，下游不必再 join，避免二次错位。

> 在此问题修复前，1.7 的下游代理实验和任何 y 分布验证都不该做——结果会被泄漏污染。
